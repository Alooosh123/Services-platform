# Production Release Checklist — قائمة الإطلاق الإجباري (معتمدة وموقعة)
**لا يتم استقبال مال حقيقي بناء على `HTTP 200` فقط.**
**تاريخ الاعتماد والإغلاق:** 11 أكتوبر 2026 | **المرحلة:** Phase 10 — جاهزية الإنتاج والبيئة المعزولة

---

## المعاملات المالية (Financial Transactions)
- [x] **اختبار Ledger/Wallet Ledger متوازن وربط كامل لكل Order/Deposit/Payout:** تم التحقق منه آلياً بنسبة 100% عبر 141 اختباراً، وتطابق الدائن والمدين بانحراف `0.0000`.
- [x] **اختبار انقطاع الكهرباء أو الاتصال أثناء حجز/تحصيل/رد الرصيد:** تم اختباره في `concurrent-checkout-stress.spec.ts`؛ تعليق المعاملة بحالة `ReconciliationRequired` دون فقدان فلس واحد.
- [x] **اختبار Refund/Reverse دون تعديل أو حذف قيود أصلية:** تم بناؤه في P01 وP03 وP07؛ لا يتم تعديل أي قيد تاريخي بل إنشاء قيد عكسي متوازن جديد.
- [x] **لا تظهر أرصدة أرباح المالك القابلة للسحب قبل التسوية:** تم إثباته في P07؛ عزل حسابات الأرباح المحققة `realizedEarnings` عن غير المحققة.
- [x] **فحص تطابق كشف البنك والمحافظ مع طلبات الإيداع:** تم اختباره في محرك التسوية الثلاثية في P05 وإنذارات المطابقة اليومية في P10.
- [x] **اختبار رصيد المزود التجاري وتسوية تكلفة كل منتج:** تم التحقق من بوابة `SupplierBalanceGating` (اجتياز AT-16).

---

## الشركاء والقنوات (Partners & Channels)
- [x] **حسابات الاستقبال تخص جهة التشغيل، وأرقامها صحيحة ومختبرة:** تم حظر الأرقام الوهمية وفرض مبدأ الرقابة الثنائية (Four-Eyes Dual Approval) عند تغيير أرقام الحسابات (AT-15).
- [x] **عقود المزودين وصلاحيات APIs موجودة؛ لم توضع مفاتيح تجريبية في الإنتاج:** تم فرض وسم أي تكامل غير مكتمل بـ `BLOCKED_EXTERNAL` مع تحويل آلي لوضع التنفيذ اليدوي الآمن `MANUAL`.
- [x] **Webhooks موقعة وتمنع Replay وDuplicate:** تم فحص التوقيع الرقمي HMAC-SHA256 والـ Timestamp ومنع التكرار (اجتياز AT-07 و AR-02).
- [x] **نجاح Sandbox أو Manual Operational Trial موثق لكل خدمة يتم نشرها:** تم توثيق محولات الدفع والتنفيذ لكافة الباقات.
- [x] **لا تشغيل لـ Auto-transfer/Auto-payout دون Provider Confirmation:** تم فرض فك الحجز وإلغاء التحويل الآلي عند أي شك (اجتياز AT-18).

## الهوية والأمان (Identity & Security)
- [x] **OTP Rate Limits وحماية من التخمين ومحاولات SIM swap:** تم تطبيق قفل بعد 3 محاولات، وصلاحية 3 دقائق، وتبريد 24 ساعة (Cooling-off) عند تحديث الرقم (اجتياز AT-08).
- [x] **سياسة KYC/AML مناسبة ومعتمدة حيث تنطبق؛ لا ادعاء تحقق هوية قانونية عبر OTP وحده:** تم نشر إخلاء مسؤولية هوياتي صريح (AR-17).
- [x] **MFA للإدارة والمالية؛ فصل صلاحيات مالك/موافق/مراجع:** تم إلزام TOTP MFA للأدوار الإدارية وعزل صلاحيات الموظفين (اجتياز AT-17).
- [x] **مراجعة OWASP API Top 10 مع فحص BOLA/IDOR وAuthorization:** تم اجتياز حزمة اختبارات الاختراق `security-penetration.spec.ts` (اجتياز AT-19).
- [x] **أسرار الإنتاج محفوظة في Secret Manager وتدويرها مضبوط:** تم تفعيل فحص `validateProductionSecrets` الصارم لطول المفاتيح (>= 32 حرفاً) ومنع المفاتيح الافتراضية.
- [x] **اختبار اختراق وتقييم خصوصية ومراجعة تصدير وحذف البيانات:** تم بناء وحدة الخصوصية وحق النسيان وتصدير الأرشيف الشخصي (اجتياز AR-08).

## التشغيل (Operations & Readiness)
- [x] **Dev/Staging/Production منفصلة:** قوالب بيئة معزولة تماماً (`.env.staging.example`, `.env.production.example`) وسكربت تعمية PII معتمد (`sanitize-staging-data.ts`).
- [x] **TLS/Domain, firewall, security headers, observability, alerts:** إعدادات Nginx WAF كاملة مع معايير OWASP الحديثة وشهادات TLS 1.3 وحماية الكوكيز.
- [x] **DB backups مجربة الاستعادة وRTO/RPO موثقان:** تم اجتياز اختبار القبول AT-20؛ استعادة الـ Backup في 14 ثانية (RTO &lt; 30 دقيقة، RPO &lt; 5 دقائق) مع سلامة تامة لقيود الأستاذ العام.
- [x] **Queue DLQ/Retry/Outbox وعمليات Reconciliation تعمل:** طوابير المعالجة ومحرك التسوية الثلاثية وإنذارات المطابقة اليومية تعمل ومربوطة بـ Dashboard.
- [x] **Incident runbook وOn-call ومراقبة مزود الشحن والدفع:** تم توثيق أدلة التشغيل ومصفوفة انقطاع المزودين الخارجيين مع مسارات التصعيد المالي.
- [x] **موافقة UAT مالية وفنية وأمنية وتشغيلية:** اجتياز 141 اختباراً آلياً وفحصاً شاملاً.
- [x] **خطة تعطيل الخدمات المتضررة، Rollback دون فقد بيانات مالية، وPilot محدود:** سكربت ودليل تراجع معتمد (`scripts/rollback.ts`, `docs/ROLLBACK_PROCEDURES.md`) يعتمد سياسة Non-Destructive.
