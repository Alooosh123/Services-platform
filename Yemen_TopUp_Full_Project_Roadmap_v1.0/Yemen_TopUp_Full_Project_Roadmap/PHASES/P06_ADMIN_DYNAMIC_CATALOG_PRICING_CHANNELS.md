## الهدف والنطاق
لوحة المدير لإضافة خدمات حسب طلب العملاء، وتعريف فئات/باقات، ونشر أسعار ربحية، وإدارة محافظ استقبال صحيحة.

## الأعمال المطلوبة بالتسلسل
1. إنشاء نموذج `ServiceRequest` لاستقبال طلبات العملاء لإضافة تطبيق أو باقة وتقييم الطلب والرد عليه.
2. إنشاء واجهات CRUD للصنف والخدمة والباقة والحقول الديناميكية والصور والترتيب وحالة النشر.
3. ضمان أن الخدمة لا تنشر دون Product Mapping ومعلومات مزود أو Manual Mode وصلاحية تنفيذ واضحة.
4. تصميم PriceRuleVersion بهرمية Default ↔ Category ↔ Service ↔ Product، Fixed Margin/Percent، صلاحية Date Range.
5. حساب Retail = Cost + Validated Fees + Policy Margin مع تحويلات العملات المسموح بها، ودعم معاينة قبل النشر.
6. حفظ تغيرات قاعدة التسعير وإصدارها وتوقيع من عدلها؛ الطلب السابق يحافظ على لقطة السعر الأصلية.
7. واجهة إضافة قناة دفع جديدة: اسم/كود/عملة/حساب استقبال مثبت/تعليمات/حدود/وضع MANUAL_VERIFY أو OFFICIAL_API.
8. اشتراط مراجعة مالية مستقلة عند تغيير رقم حساب استقبال أو تفعيل قناة جديدة أو تغيير سياسة رسوم كبرى.
9. إضافة Audit History، إيقاف منتج/قناة فورًا، وتسجيل سبب القرار؛ اختبار SEO والبحث في المتجر على الخدمات المضافة.
