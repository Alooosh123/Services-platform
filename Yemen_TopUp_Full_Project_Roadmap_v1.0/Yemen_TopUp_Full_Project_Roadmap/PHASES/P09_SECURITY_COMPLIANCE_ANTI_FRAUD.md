## الهدف والنطاق
إجراء تدقيق شامل يحمي المال والهوية والقنوات المالية ويثبت أن آلية AI لا تتجاوز القواعد.

## الأعمال المطلوبة بالتسلسل
1. فحص OWASP API Top 10، خاصة IDOR/BOLA عبر OrderID, WalletID, CustomerServiceAccount, PayoutID.
2. اختبار MFA للإدارة/المالية، rate limiting، جلسات الموظفين، password resets، OTP abuse وSIM Swap indicators.
3. مراجعة Secrets management وrotation وتوقيع webhooks وعدم قبول callbacks غير موثقة.
4. تنفيذ حدود مبالغ وسرعة طلبات وIP/Device risk وفق السياسة، وإجراءات تجميد موثقة.
5. ضبط Data Retention، حذف الرموز المؤقتة، Consent وDeletion/Export وفق التزامات المشروع.
6. فصل صلاحيات الموافقة على تغيير حساب استقبال، وفتح قناة مالية، وتسوية عالية المخاطر، وسحب أرباح المالك.
7. تنفيذ Threat Model وحالات AI prompt injection/unsafe tools/LLM hallucination والعزل عن Ledger والتصرفات المالية.
8. مراجعة متطلبات العمل المالي/تاجر الخدمة الرقمية والتسجيل وeKYC حسب النشاط والشركاء والجهة المختصة.
9. Pen Test مستقل على Staging، معالجة High/Critical، تقرير موافقة مالية/أمنية قبل إطلاق أموال حقيقية.

## بوابة الإغلاق (Definition of Done)
**لا High/Critical مفتوحة؛ قرارات امتثال مكتوبة؛ موافقة فريق الحماية والمالية.**

يجب إضافة سجل تنفيذ حقيقي يثبت: نتائج Unit/Integration/E2E، مخطط وتغييرات قاعدة البيانات، endpoints وواجهات UI، مراجع القيود المالية عند ارتباطها بالأموال، وتحديث Swagger والوثائق. أي تكامل لا يملك اعتمادًا رسميًا يوضع `BLOCKED_EXTERNAL` دون ادعاء إنجازه.
