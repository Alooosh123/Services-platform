# قائمة التحقق الأمني والرقابي (Security Checklist)
## Digital TopUp & Services Platform

تم تصميم المنصة وفق أعلى معايير أمن المعلومات والتقنية المالية لضمان سلامة العمليات وحماية الأرصدة ومنع التلاعب والاحتيال.

---

## 1. الأمان المالي والمحاسبي (Financial Security)
- [x] **سجل القيود غير القابل للتعديل (Immutable Ledger):** لا يتم تعديل أي رصيد بواسطة استعلام مباشر، بل عبر قيود قيد مزدوج `ledger_entries` مسجلة تاريخياً.
- [x] **معاملات قاعدة البيانات الصارمة (ACID Transactions):** تنفيذ عمليات حجز وخصم الرصيد بداخل `Serializable Transactions` لمنع الخصم المزدوج تحت الضغط العالي.
- [x] **مفاتيح منع التكرار (Idempotency Keys):** إلزامية توليد واستخدام مفتاح `idempotency_key` فريد لكل طلب لمنع تكرار تنفيذ الطلب أو الخصم في حال انقطاع الشبكة.
- [x] **منع الأرصدة السالبة (Negative Balance Prevention):** فحص رصيد المحفظة قبل إجراء أي عملية شراء، ورفض العملية فوراً عند عدم كفاية الرصيد.
- [x] **الاسترداد الآمن التلقائي (Safe Auto-Refund):** في حال رفض مزود الشحن للطلب أو انقطاع الخدمة، يتم إرجاع المبلغ كاملاً إلى محفظة العميل بقيد مالي `REFUND` موثق.

---

## 2. إدارة الصلاحيات والوصول (RBAC & Authentication)
- [x] **تشفير كلمات المرور (Password Hashing):** استخدام خوارزمية `bcrypt` مع Salt Rounds = 10 لجميع كلمات المرور.
- [x] **رموز الوصول والتحديث (JWT Access & Refresh Tokens):** صلاحية الرمز اليومي (1 Day) مع تجديد آمن عبر Refresh Tokens.
- [x] **فصل الصلاحيات الإدارية (RBAC):**
  - `SUPER_ADMIN`: الصلاحيات الكاملة وإدارة المشرفين.
  - `FINANCIAL_OFFICER`: مراجعة السجلات المالية والموافقة على التعديلات المحاسبية.
  - `OPERATIONS`: إدارة المنتجات ومزودي الشحن والطلبات.
  - `SUPPORT_AGENT`: متابعة تذاكر الدعم وحالات شحن اللاعبين دون صلاحيات مالية.
  - `CUSTOMER`: متجر الشحن، إدارة المحفظة الخاصة، وسجل الطلبات.
- [x] **سجل الرقابة الإداري (Audit Logs):** تسجيل كل إجراء ينفذه أي مشرف (معرف الموظف، نوع العملية، القيم القديمة والجديدة، عنوان الـ IP والتوقيت).

---

## 3. حماية واجهات البرمجة والشبكة (API & Network Hardening)
- [x] **فحص وتدقيق المدخلات (Strict Validation):** استخدام `class-validator` و `ValidationPipe` مع تفعيل خاصية `whitelist` لحذف أي حقول غير مصرح بها.
- [x] **فحص حقول اللاعب بالـ Regex:** فحص معرّفات اللاعبين وسيرفرات الألعاب ديناميكياً وفق التعبير النمطي المحدد لكل لعبة في الـ Backend قبل الإرسال للمزود.
- [x] **عزل مفاتيح المزودين (Provider Secrets Isolation):** تخزين مفاتيح الـ API في الـ Backend وقاعدة البيانات المشفرة فقط، وعدم تسريبها إطلاقاً لواجهات الويب أو تطبيقات الهاتف.
- [x] **تحديد معدل الطلبات (Rate Limiting):** حماية مسارات تسجيل الدخول والشحن من هجمات التخمين والفيضان عبر `ThrottlerModule`.
