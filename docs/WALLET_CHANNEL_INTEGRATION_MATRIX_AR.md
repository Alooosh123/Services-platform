# مصفوفة ربط المحافظ اليمنية وتشغيل الوكلاء

تاريخ المراجعة: 9 نوفمبر 2026

## قرار التفعيل

لا تُفعّل قناة استقبال أموال لمجرد إضافة رقم حساب. يلزم حساب استقبال تجاري/تفويض مكتوب، واعتماد تنظيمي ساري يغطي نوع التحصيل والصرف والمنطقة، واتفاقية تاجر مع المزود، وإثبات ملكية الحساب، ومراجعة مالية مستقلة. إذا لم توجد API منشورة، يمكن تشغيل مسار وكيل يدوي فقط إذا سمحت الاتفاقية والترخيص بذلك.

**تنبيه تنظيمي:** تعميم البنك المركزي اليمني – المركز الرئيسي عدن رقم CBY/L/282/2024 بتاريخ 26 يونيو 2024 يحظر التعامل مع محافظ وخدمات دفع غير مرخصة، وذكر بالاسم محافظ كاش وجوالي وجيب ووي كاش. غياب اسم محفظة عن القائمة لا يعد ترخيصاً لها؛ يلزم تأكيد مكتوب حديث من الجهة الرقابية المختصة. https://cby-ye.com/news/703

## حزمة الوثائق المطلوبة من كل مزود

1. الاسم القانوني للمزود ورقم الترخيص/الموافقة التنظيمية ونطاقها وتاريخ سريانها.
2. عقد تاجر/وكيل باسم الكيان القانوني للمنصة، يجيز التحصيل والصرف ويحدد المحافظ والعملات والمناطق والعمولات.
3. خطاب إثبات ملكية حساب الاستقبال التجاري واسم صاحبه، وآلية التسوية وكشف الحساب.
4. دليل API رسمي مؤرخ/مرقم، Base URL للـ Sandbox وProduction، وواجهات الدفع والاستعلام عن الحالة والرصيد والاسترداد والتسوية إن توفرت.
5. تفاصيل OAuth/HMAC/RSA أو أي مصادقة مستخدمة، نماذج التوقيع، IP allowlist، مفاتيح مختلفة لكل بيئة.
6. مواصفات Webhook، التوقيع والطابع الزمني وإعادة المحاولة، حالات UNKNOWN والـ idempotency.
7. Merchant ID، مفاتيح اختبار، أرقام اختبار اصطناعية صادرة من المزود، حالات نجاح/رفض/تأخير/تكرار.
8. SLA، حدود المعدل، رموز الأخطاء، جهة الدعم والتصعيد، وشروط الانتقال للإنتاج.

## إجراءات الوكلاء عند عدم وجود API

- يحصل الوكيل على مستخدم فرعي/صلاحية رسمية من المزود، ولا تتم مشاركة PIN/PUK/OTP أو كلمة مرور صاحب المحفظة.
- يستلم مهمة من النظام، ويتحقق من الحركة داخل تطبيق/كشف حساب المحفظة الفعلي.
- يسجل المبلغ والعملة والمرجع وآخر أربعة أرقام للحساب المقابل ومرجع إثبات من سجل المحفظة.
- أي اختلاف يحول الحركة إلى NEEDS_REVIEW.
- موظف مالية مستقل يراجع كشف المحفظة ويعتمد العملية.
- في المعاملة نفسها يرحّل النظام قيد الأستاذ ويحدث الإيداع/السحب إلى POSTED.
- صورة العميل وحدها ليست إثبات تسوية؛ والوكيل لا يمنح الترخيص ولا يتجاوز القيود النظامية.

راجع أيضاً الملف التنفيذي في مستودع المشروع بعد مراجعة PR.
