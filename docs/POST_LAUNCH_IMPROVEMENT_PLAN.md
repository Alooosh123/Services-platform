# خطة التحسين والتطوير بعد الإطلاق (Post-Launch Improvement Plan)
## خارطة الطريق للإصدارات التالية (Release 1.1+ Roadmap)
**تاريخ الإعداد:** 11 أكتوبر 2026 | **الإصدار:** v1.0 | **المرجع:** `P11` & `P12`

---

## 1. الأهداف الاستراتيجية لفترة ما بعد الإطلاق (Post-Launch Objectives)
1. الانتقال الآمن من فترة الإطلاق التجريبي (Pilot) إلى التشغيل التجاري المفتوح بعد تثبيت سلوك القنوات والمزودين.
2. التوسع في شراكات بوابات الدفع المحلية ومزودي الشحن الرسميين.
3. تعزيز تجربة المستخدم وتطوير تطبيقات الهواتف الذكية الأصلية (Native Mobile Apps).
4. أتمتة الجوانب التشغيلية وتقليل التدخل البشري مع الحفاظ الصارم على الرقابة المحاسبية المزدوجة.

---

## 2. مصفوفة التحسينات المقررة للإصدار Release 1.1+

| المحور / الميزة | الوصف التقني والتشغيلي | الأولوية | الأثر المتوقع |
| :--- | :--- | :---: | :---: |
| **تكاملات بوابات الدفع الرسمية** | استبدال المحولات التجريبية بربط واجهات API تجارية رسمية مع البنوك والمحافظ اليمنية (الكريمي، بنك اليمن والكويت، محفظة كاش). | `CRITICAL` | أتمتة الإيداع اللحظي وتقليل الاعتماد على الفحص اليدوي. |
| **تطبيق الجوال الأصلي (Flutter / React Native)** | بناء تطبيق جوال متقدم يعمل على iOS و Android إلى جانب تطبيق PWA الحالي. | `HIGH` | زيادة وصول العملاء وتحسين سرعة الشحن وسهولة حفظ المعرفات. |
| **محرك التسعير الديناميكي الذكي (Dynamic FX & Margins)** | تحديث تلقائي لهوامش الأسعار بناءً على تقلبات أسعار الصرف الرسمية في السوق اليمني وتكاليف المزودين. | `HIGH` | حماية هوامش أرباح المنصة من التآكل بسبب فروقات الصرف. |
| **برنامج ولاء ونقاط المكافآت (Loyalty Points & Cashbacks)** | نظام نقاط ومكافآت لكل عملية شحن يتم قيده محاسبياً في الأستاذ العام كالتزام تسويقي منفصل. | `MEDIUM` | رفع معدل تكرار الشراء والاحتفاظ بالعملاء النشطين. |
| **توسيع طابور المزودين المتعددين (Multi-Provider Smart Routing)** | التوجيه الآلي للطلب إلى المزود الأسرع والأقل تكلفة عند توفر أكثر من مزود لنفس الباقة، مع التحول التلقائي عند التعطل. | `HIGH` | رفع نسبة نجاح الشحن الفوري إلى أكثر من 99.5%. |

## 3. خطة المراقبة الدورية وإدارة الأداء (Maintenance Cadence)
- **يومياً:** مراجعة تقرير إقفال اليوم (Daily Close) ومطابقة كشوفات البنوك مع رصيد الأستاذ العام.
- **أسبوعياً:** فحص مؤشرات زمن الاستجابة (p95/p99) ونسبة أخطاء المزودين الخارجيين وتعديل الأسعار عند الحاجة.
- **شهرياً:** تجربة استعادة النسخ الاحتياطي (Disaster Recovery Drill AT-20) ومراجعة الصلاحيات وحسابات المدراء.
- **ربع سنوياً:** تدقيق أمني شامل (Security Pen-Test) وتحديث حزم البرمجيات والمكتبات.
