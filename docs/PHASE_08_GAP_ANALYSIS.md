## 2. المخاطر والضوابط الصارمة (Risks & Controls)

1. **خطر انقطاع الإنترنت أو تذبذب الشبكة في اليمن (Weak Network / Flaky Connection):**
   - *التحكم:* استخدام مفتاح فريد لعدم التكرار (`idempotencyKey`) في كل عملية إرسال تذكرة أو رسالة أو طلب شحن، وتثبيط الأزرار فور الضغط لمنع تكرار الإرسال مرتين عند بطء الاستجابة.
2. **خطر تسريب بيانات عميل لعميل آخر (BOLA / Multi-Tenant Leakage):**
   - *التحكم:* فرض فحص ملكية العميل للطلب والتذكرة والإشعار في كل استعلام (`where: { id, userId }`). لا يُسمح للعميل بالوصول لأي تذكرة أو إشعار لا يخصه.
3. **خطر كشف الملاحظات الداخلية لموظفي الدعم للعميل (Internal Staff Notes Exposure):**
   - *التحكم:* تمييز الرسائل بحقل `isInternalNote: boolean`. في واجهات واستجابات العملاء، يتم استبعاد أي رسائل داخلية تلقائياً (`where: { isInternalNote: false }`).
4. **خطر إرسال إشعار بنجاح العملية قبل تأكيد المزود الفعلي:**
   - *التحكم:* حظر إطلاق إشعارات النجاح إلا بعد وصول حدث مكتمل ومؤكد من محول المزود (`FulfillmentService`) أو بعد قيد الإيداع في دفتر الأستاذ العام.

## 3. خطة التنفيذ المنهجية (Step-by-Step Implementation Plan)

1. **الأنواع المشتركة وSchema قاعدة البيانات:**
   - تحديث `packages/shared/src/enums/index.ts` بإضافة `TicketStatus`, `TicketPriority`, `TicketCategory`, `NotificationType`, `NotificationStatus`.
   - تحديث `packages/shared/src/types/index.ts` بـ DTOs التذاكر والإشعارات.
   - تحديث `packages/database/prisma/schema.prisma` بإضافة نماذج `SupportTicket`, `TicketMessage`, `Notification`.
   - توليد Prisma Client وبناء الحزم المشتركة.
2. **الخدمات الخلفية (Backend Modules):**
   - تطوير `apps/backend/src/modules/support`: إدارة التذاكر، الرسائل، تشخيص الطلبات، ومعالجة النزاعات.
   - تطوير `apps/backend/src/modules/notifications`: بث واسترجاع وتحديث حالة الإشعارات.
   - تحديث `app.module.ts` لتسجيل الوحدات الجديدة.
3. **الاختبارات الآلية (Acceptance Tests):**
   - إنشاء `apps/backend/src/modules/support/support-notifications.spec.ts` لتغطية مسار التذاكر، عزل البيانات (BOLA)، حجب الملاحظات الداخلية، وعدم التكرار.
   - تشغيل حزمة الاختبارات الشاملة للمنظومة والتأكد من نجاحها 100%.
4. **تطوير واجهات الجوال والدعم (Frontend UI):**
   - **`web-customer`**: إضافة صفحة `/support`، مركز الإشعارات `/notifications` وعداد الإشعارات في الـ Navbar، وملف `manifest.json` لـ PWA مع تحسين التجاوب للهواتف الاقتصادية.
   - **`web-admin`**: إضافة صفحة `/support` لموظفي الدعم الفني لمتابعة التذاكر والرد وحل النزاعات.
5. **التحقق والتشغيل المباشر والتوثيق:**
   - بناء واختبار التطبيقات، تشغيل الخوادم، وإصدار التقرير النهائي.
