## مستجدات الوثائق العامة للوسطاء
- **Esaalat:** وثائق Merchant API تصف payment intents وحالات الدفع وWebhook موقّعاً بـHMAC-SHA256، وتعرض Test Wallet معزولة. الموقع يصرح بأنه غير تابع للمحافظ، ويعتمد على قراءة SMS من هاتف التاجر. مرشح تقني فقط، ولا يُعتمد قبل العقد والموافقة التنظيمية واختبارات التلاعب وإعادة الإرسال.
- **OnePay:** يعرض REST API، وتذكر وثائق إضافة التاجر أن Sandbox يتطلب الانضمام إلى Sandbox Manager وأن مفاتيح الإنتاج لا تعمل في Sandbox. اتفاقية التاجر تشير إلى احتمال مرور المعاملات عبر مزودي دفع أطراف ثالثة؛ يجب معرفة الجهة المستلمة والمسؤولة عن التسوية.
- **YemenPay:** API العامة تصف حقل amount على أنه Float، كما أن SDK Playground يعلن رقم اختبار لمحاكاة النجاح. لا تستخدم محاكاة SDK لإثبات دفع أو قيد محاسبي.

# سجل طلبات API والاعتماد التجاري — المحافظ ومزودو الألعاب

**تاريخ الإعداد:** 2026-11-09  
**الحالة:** جهات الاتصال العامة تم التحقق منها مبدئياً؛ لم يتم إرسال أي طلب أو إنشاء حساب تاجر أو استلام بيانات Sandbox/Production.

> جميع بيانات التواصل أدناه مأخوذة من صفحات رسمية أو صفحات دعم مرتبطة بالجهة. قبل الإرسال، راجع عنوان المستلم من جديد. لا تضع أي مفاتيح أو كلمات مرور في البريد العادي. لا يتم تفعيل قناة في Production إلا بعد إثبات الترخيص/الموافقة الحالية، عقد تجاري، ونجاح الاختبارات.


## تحديث تنظيمي واجب التحقق قبل مراسلة أي مزود — 10 نوفمبر 2026

**تجميد التعامل مع Easy Wallet:** عدة تقارير يمنية بتاريخ 29 أكتوبر 2026 تنقل أن قرار النائب العام رقم 20 لسنة 2026 وتعميم البنك المركزي `CBY/A/12/2026` المؤرخ 28 أكتوبر يشملان Easy Wallet التابعة لشركة ثروات، مع حجز/تجميد الأموال وحظر المعاملات. لم أتحقق من نسخة أصلية موقعة للتعميم من مصدر حكومي مباشر؛ لذلك لا ترسل طلب ربط أو تنفذ تحصيلاً مع Easy قبل استلام النسخة الرسمية وتأكيد مكتوب من محامٍ والجهة المختصة أن التعامل مسموح في نطاق تشغيل المنصة. لا يُعامل ظهور زر API في موقع Easy كاستثناء من أي حظر.

**تمييز الأسماء:** Saba Cash التابعة لسبأفون المذكورة في التغطية ليست Cash Pay التابعة لـTamkeen/Cash Wallet. رمز `CASH` بالمشروع يخص Cash Pay/Tamkeen وفق بياناته الحالية. لا تخلط الكيانين.

**YemenPay (وسيط طرف ثالث):** توجد وثائق API عامة، لكن المستودع العام المرتبط به يعلن أوضاع محاكاة Checkout، بما فيها نجاح فوري بكلمة `success` ونجاح تجريبي تلقائي بنسبة 80% في المسارات الأخرى. لا يستخدم ذلك كإثبات تحويل حقيقي أو لتفعيل القيد المزدوج. لا تعتمد البوابة حتى تقديم مستند KYB وترخيص/موافقة مناسبين، عقد تاجر، وصف توقيع/مصادقة قابل للتدقيق، Sandbox حقيقي منفصل، Webhook موقّع، وآلية تسوية/استرداد قابلة للمطابقة.

**التحقق التنظيمي:** الصفحة الرسمية للبنك المركزي تنشر قائمة شركات الصرافة ووكلاء الحوالات المرخصين للعام 2026، لكنها لا تثبت وحدها ترخيص كل محفظة أو كل نشاط تحصيل تاجر. اطلب خطاباً حديثاً يحدد الاسم القانوني للمشغل، الترخيص، نوع النشاط، المحافظ/الحسابات المسموح بها، ونطاق العمل الجغرافي.

## 3. الحزمة الموحدة التي يجب تقديمها للجهات
1. الاسم القانوني والشكل القانوني وبلد التسجيل والعنوان.
2. السجل التجاري/ترخيص مزاولة النشاط، إن وجد.
3. بيانات المالك والمفوض بالتوقيع وإثبات صلاحية التفويض.
4. حساب تجاري باسم المنشأة لاستلام التسويات.
5. رابط موقع/تطبيق المنصة، وصف النشاط والمنتجات والأسواق المستهدفة.
6. شروط الاستخدام، الخصوصية، سياسة الاسترداد والشكاوى.
7. وصف مكافحة الاحتيال وKYC/AML وحماية البيانات، حسب ما تطلبه الجهة.
8. خطاب طلب حساب تاجر/شريك وبرنامج API/Sandbox.

لا تُرسل المستندات الحساسة إلا عبر قناة رفع آمنة تحددها الجهة بعد التحقق من المستلم.

## 4. مدخلات يدوية لازمة من مالك المشروع
- تعبئة الحقول في حزمة الخطابات: الاسم القانوني، الشكل القانوني، بلد ومكان التسجيل، رقم السجل/الترخيص، العنوان، اسم المفوض وصفته، البريد التجاري والهاتف، رابط الموقع أو التطبيق.
- إنشاء/تأكيد حساب تجاري لدى كل مزود عندما يطلب ذلك.
- إتمام CAPTCHA وOTP وتأكيد البريد/الهاتف وتوقيع الاتفاقيات ورفع مستندات KYB بنفسه.
- إدخال أسرار Sandbox/Production مباشرة في Secret Manager أو بيئة السيرفر، لا في GitHub أو المحادثة.

## 5. شروط الإطلاق
- لا تُرسل أو تُنفذ مدفوعات قبل تأكيد الترخيص/الموافقة التجارية الحالية.
- لا تستخدم محفظة شخصية أو حساباً شخصياً للمنصة دون موافقة مكتوبة تسمح بالاستخدام التجاري.
- لا تطلب PIN/OTP أو كلمات مرور المستخدمين أو الوكلاء، ولا تعتمد على صور الإيصالات وحدها.
- لا يتم شحن لعبة أو إكمال طلب مدفوع إلا بعد تأكيد حقيقي من المزود، مع idempotency وحفظ مرجع المعاملة ومطابقة دفتر الأستاذ.
- أي Timeout مجهول النتيجة ينتقل إلى reconciliation/manual review ولا يعاد الطلب تلقائياً.
