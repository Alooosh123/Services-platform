## تنبيه مهم حول النشر
حتى تاريخ 25 نوفمبر 2026، لا توجد بيانات اعتماد أو إعداد نشر فعلي إلى VPS أو Staging أو Production في هذا المستودع. كانت وظائف CI السابقة تطبع رسائل `echo` فقط، ولذلك لا تثبت نشر التطبيق أو تنفيذ Health Probe أو Restore Drill. تم تغيير هذه الوظائف إلى `if: false` لتظهر كـ Skipped بدلاً من نجاح مضلل.

## ما يلزم قبل تفعيل النشر
1. تحديد مزود الاستضافة ومعلومات VPS والدومين وطرق الوصول.
2. إعداد بيئة Staging منفصلة مع أسرار GitHub Actions/OIDC أو SSH محدود الصلاحية.
3. إنشاء خطوات نشر حقيقية قابلة للتكرار مع health/readiness checks بعد النشر.
4. تنفيذ Backup ثم Restore Drill على قاعدة Staging مع قياس RTO/RPO والتحقق من Ledger.
5. إعداد خطة Rollback قابلة للتنفيذ فعلياً ومجربة.
6. حماية Production Environment بموافقة يدوية مستقلة وقيود نشر.
7. بعد اكتمال الشروط، استبدال وظائف deployment skipped بعمليات المزود الحقيقية مع اختبار منفصل.
