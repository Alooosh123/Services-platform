# Services-platform + n8n — الدفعة الأولى

هذه الدفعة تضيف طبقة تشغيل ومراقبة محلية فوق Backend الحالي، ولا تنقل منطق الأموال أو الصلاحيات إلى n8n.

## نطاق الدفعة

1. **مدير العمليات المركزي:** استقبال أحداث تشغيل غير مالية، تطبيع الحدث وتوجيهه للتلخيص والتنبيه.
2. **مراقبة البنية التحتية:** فحص Backend من خلال `GET /api/health` وقراءة الحالة الصحية فقط.
3. **النسخ الاحتياطي والتعافي:** استقبال دليل نجاح النسخ أو الاستعادة بعد أن تنفذ أدوات PostgreSQL العملية الفعلية محلياً.

## الحزمة القابلة للاستيراد

ملفات Workflow JSON وPowerShell والاختبارات المحلية تم تسليمها في ملف ZIP منفصل باسم:

`Services-platform_n8n_Phase1_Local_Operations_v1.1.zip`

بعد فك الضغط، استورد مجلد `workflows` بالترتيب التالي:

1. `12_NOTIFICATION_DISPATCHER.json`
2. `14_GLOBAL_ERROR_HANDLER.json`
3. `01_OPERATIONS_ORCHESTRATOR.json`
4. `02_INFRASTRUCTURE_WATCH.json`
5. `02_INFRASTRUCTURE_WATCH_SCHEDULE.json`
6. `03_BACKUP_DR_EVIDENCE.json`
7. `00_CORE_EVENT_ROUTER.json`

كل التدفقات تبدأ غير نشطة. لا تفعّلها قبل ربط الاعتمادات واختبار المسارات محلياً.

## إعدادات محلية

- n8n: `http://127.0.0.1:5678`
- Backend: `http://127.0.0.1:4000`
- فحص Backend: `GET /api/health`
- لوحة الإدارة: `http://127.0.0.1:3001`
- المنطقة الزمنية: `Asia/Aden`

إذا كان n8n داخل Docker، استبدل localhost/127.0.0.1 بعنوان المضيف الذي يمكن للحاوية الوصول إليه، مثل `host.docker.internal` في Docker Desktop.

## بيانات الاعتماد

أنشئ داخل n8n:

- Header Auth باسم `SP Agent Inbound`، وترويسة `X-SP-Agent-Token`.
- Telegram API Credential باسم واضح، إن أردت إرسال تنبيهات Telegram.
- بيانات اعتماد نموذج الذكاء الاصطناعي إذا استخدمت نموذجاً خارجياً.

لا تحفظ الأسرار في Git أو ملفات Workflow أو رسائل Telegram. لا تستخدم حساب مدير المنصة كحساب خدمة.

## حدود الأمان

- لا اعتماد إيداعات.
- لا إضافة رصيد لمحفظة.
- لا كتابة إلى Ledger.
- لا تنفيذ سحب أو حوالة.
- لا تشغيل أو إيقاف PostgreSQL أو Redis أو Backend.
- لا استعادة إلى قاعدة إنتاج.
- لا إرسال بيانات شخصية أو إيصالات أو مفاتيح مزود إلى نموذج الذكاء الاصطناعي.

## حالة التحقق

هذا المستودع يثبت عقود الربط والمسارات المستخدمة. أما استيراد JSON وربط credentials واختبار n8n المحلي فيحتاج جهاز Windows الذي يشغل n8n؛ لا تعتبر الملفات مستوردة أو نشطة قبل ظهور تنفيذ ناجح داخل n8n.
